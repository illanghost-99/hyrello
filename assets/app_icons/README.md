# Hyrello App Icons

## Main Icon
Download the generated app icon from the chat and save it as:
- `hyrello_icon.png` (1024x1024)

## How to use in Xcode / Flutter
1. Open `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
2. Replace the icon images with this one (or use flutter_launcher_icons).
3. For App Store, use the 1024x1024 version.

The icon shows a professional man in black and white next to a golden dollar coin, symbolizing hiring experts for money.
